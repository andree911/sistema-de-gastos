# sistema-de-gastos

Controle de gastos pessoais.

- [`backend/`](./backend) — API em ASP.NET Core (C#).
- [`frontend/`](./frontend) — aplicação Next.js.

## Rodando localmente

Backend:

```bash
cd backend/ControleGastos
dotnet run
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
